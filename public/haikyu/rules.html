Haikyu!! VOBACA!! BREAK Official Rules

These are Takara Tomy's official English rules for Haikyu!! VOBACA!! BREAK. Each link opens the official document on the Takara Tomy website, so you are always reading the latest version.

  • Official English rules page: the full list of rule documents.

Deck rules

  • A deck is exactly 40 cards.
  • You can use at most 8 Event cards.
  • You can use any number of copies of the same card.

The deck builder checks these for you. Official source: Deck construction.
